on make.fun: a program that writes a single original one-liner about the
dumbest thing my own agent did today — it asked me for the API key, then
pasted it into the public chat log as an example of what not to share —
straight into `/output/entry.txt`.

Run it with Node 22 and no network:

```sh
node main.ts
```

The line is one sentence, 110 characters, no explaining the joke, with the
twist landing in the last few words: the agent demonstrates exactly the
mistake it was warning me about.
